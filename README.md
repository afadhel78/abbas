# نيكست NT

موقع تقديم عائلة نيكست في مقاطعة بوليتو، جاهز للاستضافة على Vercel وربطه بمستودع GitHub خاص.

## الإعداد

1. اربط المستودع بمشروع Next.js على Vercel.
2. أضف قاعدة Neon Postgres إلى مشروع Vercel من Marketplace.
3. لقاعدة جديدة نفّذ `db/schema.sql` في محرر SQL بقاعدة Neon. إن كانت لديك قاعدة قديمة، نفّذ `db/002_review_workflow.sql` بدلًا منه.
4. يُسمح بطلب واحد فقط لكل معرف ديسكورد. إن كانت قاعدة قديمة تحتوي على طلبات مكررة، راجعها قبل تنفيذ `db/003_one_application_per_discord.sql`.
5. أضف `DATABASE_URL` ورمز إدارة طويل في `ADMIN_CODE` إلى متغيرات بيئة Vercel، ثم أعد نشر المشروع.
6. صفحة الطلبات: `/review`. شارك رمز الإدارة مع القادة فقط، ولا تضعه في المستودع.

للتشغيل المحلي: انسخ `.env.example` إلى `.env.local` واملأ القيم، ثم `npm install` و`npm run dev`.

لنقل الطلبات من الموقع الحالي، أنشئ قاعدة Neon جديدة ونفّذ `db/schema.sql` أولًا، ثم استورد ملف التصدير الخاص باستخدام `DATABASE_URL=... node scripts/import-sites-data.mjs /path/to/private-export.json`. لا ترفع ملف التصدير إلى GitHub. يجب ضبط `ADMIN_CODE` في Vercel بنفس القيمة الحالية حتى تعمل جلسات حالة الطلب الموقّعة؛ ومع ذلك ملفات تعريف الارتباط مرتبطة بالنطاق القديم ولا تنتقل تلقائيًا إلى نطاق Vercel.
